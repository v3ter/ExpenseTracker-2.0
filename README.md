# Expense Tracker 2.0

Консольное приложение на Python для учёта личных финансов.

## Возможности

- Добавление доходов и расходов.
- Просмотр общего баланса.
- Подсчёт общей суммы доходов и расходов.
- Статистика расходов по категориям.
- Определение самой затратной категории.
- Сохранение и загрузка данных в формате JSON.
- Проверка пользовательского ввода и обработка ошибок.

## Технологии

- Python 3
- ООП (объектно-ориентированное программирование)
- Наследование
- Работа с JSON
- Обработка исключений
- Git и GitHub

## Запуск проекта

1. Склонируйте репозиторий:

```bash
git clone https://github.com/v3ter/ExpenseTracker-2.0.git
```

2. Перейдите в папку проекта:

```bash
cd ExpenseTracker-2.0
```

3. Запустите программу:

```bash
python main.py
```
